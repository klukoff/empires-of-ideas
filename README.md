# Empires of Ideas: A Reading Atlas

A visual companion to William C. Kirby’s *Empires of Ideas* (2022).

[Open the website](https://klukoff.github.io/empires-of-ideas/).

Includes annual ARWU ranking histories for eight profiled universities, optional MIT/Caltech comparisons, institutional profiles, critical arguments, and a dated update covering developments since publication. Sources and data downloads are available in the site.

Static HTML, CSS, and JavaScript, published with GitHub Pages from the root of `main`. No build step is required. Ranking bands and unavailable observations are preserved. Data checked October 18, 2026.
